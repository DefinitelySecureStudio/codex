# Context Package v1 JSON Schema

`context-package.schema.json` is the normative Draft 2020-12 schema for the
three Context Package v1 document kinds: inline packages, detached artifact
references, and explicit authorization decisions.

Schema validation establishes document shape. Consumers must also enforce the
canonical identities, byte/hash arithmetic, unique keyed identities,
classification ordering, time windows, source links, authorization scope, and
prompt-slot compatibility defined by the specification.
