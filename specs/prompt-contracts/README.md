# Prompt contracts

Stable prompt inputs, outputs, invariants, error behavior, and evaluation
requirements belong here. Experimental prompt text remains in `lab`; real prompt
instances containing unrevealed context remain private.

## Contracts

- [Prompt Definition Specification v1.0.0](prompt-definition-v1.md) defines the
  portable, provider-neutral prompt document.
- [Prompt definition versioning](VERSIONING.md) defines compatibility,
  lifecycle, deprecation, and breaking-change rules.
- [Prompt Definition v1 conformance record](PROMPT-DEFINITION-V1-CONFORMANCE.md)
  records the constitutional assessment of this contract candidate.
