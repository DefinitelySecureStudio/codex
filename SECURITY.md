# Security policy

## Supported versions

The Codex has no released contract versions yet. A support matrix will be added
before the first stable release.

## Reporting a vulnerability or sensitive disclosure

Do not open a public issue if a schema, example, fixture, or document exposes a
credential, private context, proprietary lore, personal data, or other sensitive
material. Do not publicly disclose a contract weakness that could compromise a
consumer before maintainers have assessed it.

Use GitHub's private vulnerability reporting:

<https://github.com/DefinitelySecureStudio/codex/security/advisories/new>

Include the affected contract and version, impact, reproduction details using
synthetic data, and a suggested mitigation when available. Maintainers will
coordinate remediation, consumer notification, and disclosure timing.
